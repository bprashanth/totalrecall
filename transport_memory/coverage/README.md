# Round 2 coverage artifacts (transport)

`matrix.json` — regenerated from admitted question banks by `python3 harness/coverage.py`
(breaker and holdout banks excluded by default; `--include-breakers/--include-holdouts` to
audit them). One row per question: gold skeleton, op multiset, source families (inferred by
mirroring the executor's routing order exactly, overridable with explicit `source_family`
metadata), grains, time form, relation polarity/thresholds, aggregate/compare/estimate
vocab used, rank arity, holes, and capability family.

The matrix is the guard against fake breadth: paraphrases add rows, never new skeletons,
sources, grains, or cells. The `summary.cells` section lists empty/singleton
(source x type) and (type x skeleton) cells — those, not raw counts, drive gen-003 and the
holdout generation prompts (ROUND2.md workstream B).

Round-1 baseline (45 questions, before Round-2 generation): 11 unique skeletons; osm-routes
appears in exactly ONE question; gtfs-mobility-database and city-open-data-ridership in zero;
world-bank has no STATE/COMPOSITE cells; relations `distance` and `cooccur` unused; ESTIMATE
method `interpolate` unused.

`source-census.json` — cache-backed integrity snapshot of all five adopted source families,
regenerated by `python3 harness/source_census.py`. Every probe checks nonempty / unique /
ordered / numeric-bounded rows as appropriate to its kind, and records grain plus upstream
evidence status (observed administrative vs upstream-modeled). Negative controls verify that
unregistered cities produce honest empties (DataRequests), never silent fallbacks. Rejected
candidates (keyed APIs, partial years, Round-1 phantom indicators) are listed with reasons.
