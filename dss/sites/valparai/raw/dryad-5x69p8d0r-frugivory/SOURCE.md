The six files describe visitation rates, focal scans, focal-tree and fruit traits, and visitor
name/trait crosswalks for 131 trees observed for 623 hours. File hashes were checked against the
Dryad API manifest. Five match. `Readme.csv` has the advertised byte size but its returned content
hash (`ad9b7f…`) differs from the API metadata hash (`421ede…`); the serving adapters do not depend
on that README and the mismatch remains an explicit provenance warning.

The interaction adapters preserve observed visitor–focal-tree rows. They do not promote fruit
handling observations into successful dispersal without the corresponding behaviour and outcome.
