# Round 2 expressiveness-breaker taxonomy

These probes are not malformed golds and do not count as active parser questions. Each preserves
the full user request and asks whether frozen v2.1 can express it. Repetition across independently
generated probes is evidence for a proposal; one imaginative example is not.

| family | semantic requirement | v2.1 obstruction | candidate addition (proposal only) |
|---|---|---|---|
| `attribute_filter` | rows satisfying an attribute predicate | SELECT has no predicate and ANNOTATE cannot restrict | `FILTER(source,predicate)` with typed field/comparator/value |
| `subgroup_filter` | sex/age/industry/education slice | baking dimensions into entity names does not compose | same FILTER over declared source dimensions |
| `group_partition` | one result per sex/industry/region | AGGREGATE has only space/time, no partition key | `GROUP(source,keys,metric)` or typed AGGREGATE partition |
| `record_set` | positive union/intersection/difference | RELATE is spatial, not set algebra | `SET(items,how=union|intersection|difference)` with identity/dedupe rules |
| `derived_rate` | numerator/denominator/rate/share | COMPARE ratio loses units and denominator semantics | `DERIVE(expr)` over unit-tagged Scalars/Series, or typed arithmetic extension |
| `distribution` | median/quantile/histogram/top share | four fixed AGGREGATE metrics cannot express distributions | distribution-valued AGGREGATE plus quantile/histogram parameters |
| `temporal_alignment` | align different calendars, lags, revisions | COMPARE scalarizes endpoints without an alignment policy | `ALIGN(series,calendar,join,lag,vintage)` before arithmetic |
| `uncertainty_conflict` | intervals, flags, source disagreement, corroboration | evidence label is one enum; VERIFY absent from concrete IR | epistemic `CORROBORATE/VERIFY` claim op with source independence and conflict result |
| `multi_output` | retain two requested clauses | one expression has one root/output | dialogue-level `BUNDLE`/clause plan, not necessarily a kernel op |
| `causal_counterfactual` | effect/why/what-if claim | association and ESTIMATE are not causal identification | typed DataRequest unless a future causal claim layer declares design/assumptions |

Admission rule: no probe may be “fixed” by shrinking the gold. For example, “markets or banks” is
not a SELECT on `market`, a median is not a mean, and a sex breakdown is not a preselected total.
`questions/round2-breakers.json` is regenerated by `harness/build_round2_breakers.py` and contains
at least six surface-diverse probes per family.
