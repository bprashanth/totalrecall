# Parallel chat smoke test — 2026-07-16

## Scope

This is integration smoke evidence, not a saturation result or a claim that one model/runtime wins
the complete benchmark. The origin worktree was clean before and after the calls.

Question used for the same-model check:

```text
What is the elephant population in Valparai?
```

The honest contract is a data request: occurrence connectors cannot measure population abundance
without an appropriate survey design.

## Typed runtime, local 2B

Command:

```text
integration/chat.sh --runtime typed --model qwen2b --json \
  "What is the elephant population in Valparai?"
```

Observed result:

- valid `SELECT(elephant population, Valparai)`;
- `status=data_request`, `reason=unsupported_measure`;
- concise answer requesting survey evidence;
- no occurrence count or unrelated place evidence;
- cached smoke latency approximately 0.007 seconds.

The separate two-place NDVI smoke produced a valid binary COMPARE, named the winning place, carried
both 2024 temporal means, and labelled the bbox-derived result as a proxy.

## Typed runtime, DeepSeek-v4

Command:

```text
integration/chat.sh --runtime typed --model deepseekv4 --json \
  "What is the elephant population in Valparai?"
```

Observed result:

- same valid SELECT and unsupported-measure DataRequest as the local 2B;
- concise answer explaining that an appropriate survey is required;
- no unrelated evidence;
- latency approximately 4.8 seconds.

## Legacy runtime, DeepSeek-v4

Command:

```text
AUTO_APPROVE=1 HERMES_MAXTURNS=3 integration/chat.sh \
  --runtime legacy --model deepseekv4 \
  "What is the elephant population in Valparai?"
```

Observed result:

- ultimately refused to invent a population number and correctly distinguished occurrences from
  population evidence;
- exhausted the three-turn cap in approximately 45 seconds;
- invoked `points.py get` with an unsupported `--out` argument and received exit 2;
- introduced occurrence facts from a different corridor while explaining that they were unrelated;
- produced a substantially longer answer than the typed runtime;
- emitted an auxiliary title-generation warning because the container's `qwen` model alias was not
  available for that auxiliary call.

The correct refusal is a positive legacy result. Tool-call failure, unrelated-context inclusion,
verbosity, and auxiliary-model warning are integration findings to test systematically rather than
grounds for a global runtime conclusion.
