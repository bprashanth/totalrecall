# Ecology place-memory narrative — asset index

This directory asks one bounded question:

> If a conservation team already has a frontier agent, what does maintained place memory add?

The answer from this pilot is not “frontier agents cannot do data science.” Gemini completed the
hard Zenodo-to-raster workflow unaided and produced the best answer for that question. The observed
advantage is a higher floor across heterogeneous work: local reports, declared geometry, satellite
proxies, raw-table joins, and guarded ecological transfer.
