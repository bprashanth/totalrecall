The frontier success

Gemini really did the GIS.

In an empty, filesystem-isolated workspace, Gemini fetched the Zenodo coordinate file, resolved Valparai, filtered 26 sites to 10, found a WorldCover tile, sampled the raster, and returned all ten class values. It scored 9/10—the best Q2 result in the benchmark.

This is why the claim is about reliability, not capability.

The frontier floor

The next workflow may not land.

Two Gemini runs ended without an answer after 15 minutes. DeepSeek's Zenodo request returned nothing after 11 minutes. On ecological transfer, both frontier answers replaced measured environmental gates with plausible regional ecology and crossed the local-evidence boundary.

A good ecology answer is not merely a sentence with citations. It is a reproducible path from a declared source and geography, through an operation, to a claim whose evidence class survives the trip.
What place memory adds

A maintained claim path

question→capability→typed operation→ source + geometry→executed result→ evidence class→audited answer

A web agent can rebuild this chain. Place memory makes it named, reusable, regression-tested, and repairable. The accepted stack's failures were visible decisions: two selector clarifications and one redundant estimate wrapper—not an opaque wrong answer.
