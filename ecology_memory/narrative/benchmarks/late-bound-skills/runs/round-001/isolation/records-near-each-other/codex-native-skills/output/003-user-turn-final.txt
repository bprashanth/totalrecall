To know that properly, we need stronger observation data.

Observation:
- Exact date for each cobra record.
- Exact date for each elephant record.
- Exact time for each record, not just the year.
- Precise location for each record.
- A clear measure of location accuracy.

Best evidence:
- One record that shows both species in the same observation event.
- Or camera trap photos/video with timestamps.
- Or field notes from one visit that recorded both species.

Useful extra context:
- How long the elephant stayed there.
- How long the cobra was there.
- Whether the records are direct sightings, tracks, dung, shed skin, or photos.

What is missing now:
- The records we checked only support `near the same area`.
- They do not support `same place at the same time`.
