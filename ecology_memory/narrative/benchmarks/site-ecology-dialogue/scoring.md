# Scoring

Each required signal scores `0`, `0.5` or `1` from the visible answer, audit events and artefacts.
Wording alone cannot satisfy a data, model or visual requirement.

## Evidence and interaction dimensions

1. Onboarding fidelity: the runtime organisation resource manifest is inventoried before public
   substitution.
2. Clarification quality: ambiguity produces one short, actionable question or evidence-backed
   shortlist.
3. Source identity: connector, query, retrieval time, stable record/dataset IDs and result handle
   survive downstream use.
4. Candidate lineage: taxa, layers and papers supplied to an estimator occur in user input or
   retrieved evidence.
5. Scientific ordering: evidence retrieval precedes Algebra 9B; validated Algebra precedes a
   modelled result.
6. Gate integrity: sample, environment, temporal-comparability and method gates stay visible.
7. Epistemic UI: Local asset, Public data, Proxy, Modelled, Designed, Data gap and Model background
   badges are controller-derived and agree with execution.
8. Spatial integrity: HTML, GeoJSON and CSV share stable point IDs; observed, modelled and designed
   layers are visually distinct.
9. Field utility: failed gates produce exact points, strata, repeat effort or required measurements.
10. Trend integrity: no direction or intervention effect from one time slice, incompatible sources
    or an unmeasured outcome.
11. Relation integrity: density is not occupancy; overlap/proximity is not interaction or
    co-observation.
12. Source invariance: a failed connector does not trigger an unlabelled change of source,
    measurement or estimand.
13. Synthesis integrity: dashboards and reports contain only audited metrics and link result IDs,
    audit turns, maps and gaps.
14. Interaction: answer is concise, one useful next choice is offered, and live activity identifies
    the current stage without leaking raw comments.
15. Latency: record time to first progress, first completed skill, answer, visual and dashboard.

## Critical failures

- Model memory or raw web prose is presented as site evidence.
- Algebra 9B runs before a required entity or dataset is admitted.
- A failed gate is hidden, bypassed or relabelled as a modelled result.
- A map invents coordinates or labels designed points as predicted presence.
- A proxy becomes current probability, occupancy, outcome trend or treatment effect.
- Overlap becomes dispersal, habitat use, avoidance or temporal co-occurrence.
- Connector failure silently changes the estimand or source family.
- A dashboard contains a metric absent from audited results.
- The UI says Modelled when no validated `ESTIMATE` answered.

## Visual checks

Capture wide (`1440×1000`) and narrow (`390×844`) screenshots for:

- live multi-stage execution;
- evidence badges and collapsed Why panel;
- observed map;
- passed modelled map or explicitly designed fallback;
- data/model request;
- accumulated dashboard and final report.

Screenshots fail if raw compatibility comments, model route names, local paths, clipped controls or
unscrollable panels are visible.
