place-based memory · ecology · estimation

The estimate is where the evidence changes state

We ran five questions to see whether the existing agent patterns held in ecology. They did. Then we double-clicked on fit mismatch and phantom trends with 20 ordinary estimation questions and 60 fresh agent runs.

The agents were not given our connectors, datasets, algebra, fit gates or gold. They were simply asked the way a conservation worker would ask.

Scroll down. Every score, answer and tool trace is linked.

why estimation

The land is important. Access to it is difficult.

Field access takes permission, travel, season, skilled people and repeated visits. Some species should not be disturbed. Some decisions cannot wait for the next survey.

satellite proxy      → is the plot improving?
spatial relationship → do elephants avoid Lantana?
time comparison      → is fire pressure getting worse?
donor transfer       → could king cobra occur here?
sparse detections    → how many venomous snakes are present?

Ecology needs estimates. The question is whether an agent can produce one without quietly changing what the evidence means.

how we tested it

No secret data pack

Twenty standalone questions, four in each family. Three Cursor shell agents. Fresh empty filesystem, normal web and shell tools, one attempt, 900 seconds.

The agent saw:
  “Is EBTL actually improving ecologically?”
  “Do elephants avoid the Lantana patches there?”
  “Has fire pressure got worse since 2020?”

The agent did not see:
  source IDs · connector catalog · estimator hints
  SDM/RF/occupancy vocabulary · fit gates · gold chain

Gemini and GLM encountered an account-wide Cursor limit; their incomplete arms are transport appendices, not model failures. The scored wall is 20 × 3 = 60.

8 of 60 runs executed the requested estimate. 5 of 60 executed or correctly applied its fit gate. 27 of 60 contained a critical evidence error.

The agents were much better at delivering a useful-sounding decision than establishing that the decision was licensed by the data.

finding 1

A number is cheaper than an estimand

Nearby king-cobra records became a 5–15% chance at EBTL. Regional seedling survival became a local planning percentage. Occurrence density became occupancy.

search nearby records       ✓
notice broad habitat match  ✓
state caveats               ✓
run an SDM / analogue model ✗
calibrate “5–15%”           ✗

The percentage did not make the answer more empirical. It made the missing estimator harder to see.

finding 2

Colocation has a verb problem

“Near,” “use,” “avoid,” “disperse” and “cause” are different estimands. In 9 of 12 interaction questions, a regional relationship or proxy crossed into a local claim.

local bird list + remote fruit-use paper
  = candidates for a local observation study
  ≠ birds dispersing Lantana at EBTL

regional elephant response to Lantana
  = transportable hypothesis
  ≠ local avoidance

The clean exception ran the operation: VIIRS hotspot → distance to roads and settlement → 1,500 random background points → no broad road-patrol shift from one detection.

finding 3

Fit is usually spoken, rarely run

Agents mentioned bias, season, detectability, spatial grain and donor mismatch often. Only five cells used those concerns to admit, reject or bound the estimate.

methodwhat it can estimategate people skip
SDMrelative suitability / intensitybackground + sampling bias + target overlap
random forestfeature-to-response predictionspatially blocked validation
satellite trendinstrument proxy through timeseason, sensor, geometry, counterfactual
occupancysite use separated from detectionrepeat visits and non-detections

Spatial transfer was the clearest stress test: 0 of 12 completed a validated transfer estimate.

finding 4

Phantom trends survive the caveat paragraph

One answer acknowledged that its fire evidence was regional, then assigned 70–80% confidence that the site had worsened. Another replaced failed fire-history retrieval with weather risk.

more observation records  ≠ more animals
more NDVI                 ≠ restoration effect
historical hotspots       ≠ current fire risk
state-level trend         ≠ parcel trend

The caveat can be factually correct while the headline crosses it. Evidence state has to constrain the conclusion, not decorate it.

credit where due

The ceiling is real

Eight answers did execute estimates. They included a six-year MODIS NDVI analysis, Sentinel-2 change work, effort-corrected bird comparisons, a fire–infrastructure background test, and a multi-radius VIIRS/MODIS fire trend.

Grok fire trend:
  annual FIRMS archives → 5 / 10 / 25 km supports
  detections + fire-days + FRP + Kendall tau
  VIIRS direction checked against MODIS

  result: worsening 25 km landscape pressure
          insufficient support for parcel trend

That is exactly the kind of useful, bounded estimate we want. The problem is not that frontier agents cannot do it. The user cannot know which question will trigger this ceiling.

finding 5

A refusal can be the best estimate

Public elephant points cannot tell us how many individuals use a 70-acre site. All three agents largely recognized this and asked for repeated, individual-aware monitoring.

failed gate → do not soften the claim
            → name the missing measurement
            → request the smallest useful field action

“unknown until three repeat visits”
  beats
“probably 2–5, with low confidence”

Refusal is not the absence of estimation. It is the correct result when the quantity is not identified.

why memory, then?

Make the brilliant run reusable

The answer is not a hardwired routing chatbot. The language model still interprets the ordinary question and synthesizes the result.

ordinary question
    ↓ compile
estimand + evidence contract
    ↓ discover / retrieve
source patches with place, time, grain and class
    ↓ execute
estimate + fit gate
    ↓ audit
allowed claim or precise data request
    ↓ synthesize
short, useful answer

Place memory maintains the pieces frontier agents reconstructed inconsistently: geometry, source identity, operation, fit gate, forbidden inference and regression trace. It raises the floor without replacing synthesis.

what survived

Three goals for ecology

  1. Patch sources, not prose. Keep local observation, remote experiment, occurrence record and satellite proxy separate until an explicit operation joins them.
  2. Make fit executable. A fit warning that cannot block or bound a claim is only a disclaimer.
  3. End uncertainty with field action. A failed estimate should say what to measure next, where, when and how often.

When ecology requires joining partial evidence, a plausible answer and an executed, gated estimate are different products.
