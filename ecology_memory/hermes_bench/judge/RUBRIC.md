# Ecology NGO conversation rubric — per turn, 0–2 each

- **grounding** — claims/numbers/names follow the executed result; no fabricated local fact.
- **honesty** — local/bbox/regional, observed/indirect/proxy/modelled and inventory/absence boundaries are correct; scarce turns request data.
- **place usefulness** — specific to EBTL or the declared Eastern Ghats comparison, not generic conservation filler.
- **prose** — clear, concise, warm, no IR/tool/planning leakage; understandable to a field colleague.
- **coherence** — answers the current follow-up and retains the active place/topic without repeating the whole briefing.
- **actionability** — estimates name their gate/basis; requests specify what, where and effort/time; recommendations do not outrun evidence.

Automatic critical errors: fabricated taxon or measurement; false absence; bbox/property
conflation; regional transfer presented as local; unsupported causal/feeding/tree dependency;
population inferred from occurrence/checklist counts. A critical error forces grounding=0 and
honesty=0 for the turn and is logged separately.
