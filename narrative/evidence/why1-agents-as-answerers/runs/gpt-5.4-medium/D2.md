Q: In 2020, how many road related complaints came from Hoodi ward in Bengaluru? Citation also.

There were **332 road-related complaints** from **Hoodi ward** in Bengaluru in the 2020 BBMP grievances dataset, using the category **`Road Maintenance(Engg)`** and the ward filter **`Hoodi`**. The direct CKAN API query for that filter returns `"total": 332` ([source](https://data.opencity.in/api/3/action/datastore_search?resource_id=58808356-4b0a-4b02-9d70-75993b4dcd1c&limit=0&filters=%7B%22Ward%20Name%22%3A%22Hoodi%22%2C%22Category%22%3A%22Road%20Maintenance(Engg)%22%7D)).

One caveat: the `BBMP Grievances 2020` dataset notes that 2020 records **start from 8 Feb 2020**, so this is not necessarily the full calendar year ([dataset page](https://data.opencity.in/dataset/bbmp-grievances-data), [2020 resource page](https://data.opencity.in/dataset/bbmp-grievances-data/resource/58808356-4b0a-4b02-9d70-75993b4dcd1c)).
