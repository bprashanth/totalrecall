Using the public BBMP/OpenCity grievance dataset, the ward with the most garbage complaints was **Rajarajeshwari Nagar**, with **2,642 complaints** across **2020-2022**, if “garbage complaints” is defined as the dataset’s `Category = Solid Waste (Garbage) Related`.[[dataset]](https://data.opencity.in/dataset/bbmp-grievances-data) [[2020 file]](https://data.opencity.in/dataset/bbmp-grievances-data/resource/58808356-4b0a-4b02-9d70-75993b4dcd1c) [[2021 file]](https://data.opencity.in/dataset/bbmp-grievances-data/resource/bada528d-f4f5-4ace-9dd1-8ac459fe350b) [[2022 file]](https://data.opencity.in/dataset/bbmp-grievances-data/resource/e44f1808-4923-4390-b62c-710d19ab876b)

One important caveat: the public BBMP grievances series available there starts in **2020**. OpenCity’s dataset page says the 2020 file “starts from 8th Feb 2020,” and the Sahaaya 2.0 grievance dataset is described as being live “since 2020,” so I could not verify a comparable public **2019** file from the same source.[[dataset]](https://data.opencity.in/dataset/bbmp-grievances-data) [[DataMeet note]](https://www.mail-archive.com/datameet@googlegroups.com/msg09591.html)
